Отображаем первые две карточки

Компонент Card мы создали. И даже протестировали его, вызвав больше чем один раз. Но все карточки на одно лицо, они абсолютно одинаковые. Нам нужны данные сразу для нескольких разных карточек, чтобы убедится, что приложение работает как надо.

Поменяем в файле data.js переменную cardData на массив cards. В этом массиве хранятся объекты, каждый из которых содержит информацию о какой-то определённой яхте. Все объекты с одним и тем же набором полей и соответствуют интерфейсу, который мы задали для компонента Card.

      const cards = [
                  {
                    id: '1',
                    name: 'Катер Meridian 401',
                    description: 'Яхта 401 длиной 12.5 метров и шириной 4.2 метра',
                    img: 'img/photo-card-1.jpg',
                    price: 14000,
                    features: [
                      '2 каюты',
                      '4 спальных места',
                      'аудиосистема, кондиционер',
                    ],
                  },
                      {...}
                    ];

Нужно передать каждый объект из массива cards в свой экземпляр компонента Card, так мы отобразим данные о каждой яхте.

Для начала потренируемся на массиве из двух карточек. Выделим первый и второй элемент массива и передадим каждый из них в свой экземпляр карточки. Для это используем деструктуризацию:

const [firstCardData,secondCardData] = cards;
                        ...
                        <Card cardsData={firstCardData}/>
                        <Card cardsData={secondCardData}/>
