Заполняем шаблон из внешних данных

Мы пришли к тому, что шаблон карточки заполняется содержимым из данных. Можно изменить название яхты или количество элементов в массиве характеристик и новые данные будут отображены на странице без правок в коде шаблона. Данные и их отображение разделены. Мы можем добавить класс всем элементам списка при создании, изменить разметку элементов списка (например, добавить ссылки) или вывести список в другом месте карточки. Изменения в разметке шаблона не затронут данные.

Отделение данных от их отображения — это принцип, в соответствии с которым данные, используемые в приложении, должны храниться в отдельных частях кода, не пересекающихся с частями, отвечающими за отображение этих данных на экране. Что позволяет легче поддерживать код и обеспечивает гибкость приложения.

Отделение данных от их отображения в React — это использование функциональных компонентов, которые принимают параметры и возвращают разметку.

  • Данные для заполнения шаблона вынесем в отдельный файл data.js. Файл data.js определяет переменную cardsData — данные для карточек. Подключим файл с данными в теге head.

  • Значение переменной cardData передадим параметром в корневой компонент приложения <App cardData={cardData}/>. Теперь, чтобы отобразить в шаблоне, к примеру, название яхты, нам нужно использовать поле name параметра cardData.
