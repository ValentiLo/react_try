Для работы с ReactJS в браузере понадобятся библиотеки React и ReactDOM. Обе библиотеки подключаются скриптами в заголовке страницы, в теге head.

<script crossorigin src="https://unpkg.com/react@18/umd/react.development.js"></script>

<script crossorigin src="https://unpkg.com/react-dom@18/umd/react-dom.development.js"></script>

порядок подключения библиотек важен! Если ReactDOM не увидит подключённый React, то он выдаст ошибку.

Также необходимо показать React в каком элементе страницы нужно построить дерево компонентов. В body файла index.html находится единственный элемент div#root. Содержанием этого элемента будет управлять ReactJS, он наполнит его разметкой из описания компонентов. Назовём этот элемент «корневым элементом».

<div id="root"></div>

В корневом элементе ReactDOM создаст «корень» приложения — входную точку, из которой стартует композиция компонентов приложения. React сам создаст нужные DOM-элементы. Добавит их в корневой элемент и будет отслеживать изменения в компонентах, чтобы эффективно обновлять DOM-элементы страницы.

Стандартная схема отрисовки корня приложения React:

  • Найти на странице корневой элемент div#root и сохранить на него ссылку.
  • Вызвать метод ReactDOM.createRoot и передать ему ссылку на корневой элемент.
  • Вызвать метод render корня приложения, чтобы запустить отрисовку DOM-элементов. В простейшем случае это может быть строка.
const rootElement = document.getElementById('root');
      const root = ReactDOM.createRoot(rootElement);
      root.render('Реакт подключён!');

Эта схема повторяется для любых приложений.

Если библиотеки подключены и работают правильно, в результате на странице браузера отрисуется корневой элемент, содержимое которого заполнено из кода приложения.
