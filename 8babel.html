Переносим разметку карточки в компонент

Шаблон карточки готов. Данные в него поступают из внешнего источника. Но в каталоге будет несколько таких карточек. Чтобы не дублировать строки кода, вынесем код создания карточки в отдельный компонент. Новый компонент скроет внутри себя подробности подготовки элементов шаблона. Используя отдельный компонент, мы легко сможем вызвать его в различных местах приложения и для этого нам не нужно повторно писать код для форматирования данных и их отображения.

Задача — перенести код формирования разметки карточки в функцию Card. 

      function Card({cardData}) {
  ...
