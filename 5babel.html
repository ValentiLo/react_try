Форматируем данные

Часто формат вывода данных в макете может требовать дополнительной подготовки. Как, например, это происходит с ценой. В данных она хранится в виде 14000, а вывести её нужно с разделителем, то есть так:14 000

В этом случае нам пригодится метод toLocaleString(). Он преобразует число в строку и возвращает значение, используя указанный языковой стандарт. Если метод используется без параметров, то он использует язык по-умолчанию.

Например, для числа 1500 метод toLocaleString() в русской локализации вернёт строку 1 500, то есть добавит пробелы между триадами разрядов.

Пример

price.toLocaleString()

Но этом преображение цены не заканчивается. Если вы внимательно изучили карточку яхты, то, наверняка, заметили, что к цене добавляется единица измерения. Единицу измерения удобно добавить с помощью интерполяции шаблонной строки.

Интерполяция шаблонной строки — это техника для вставки вычисленных значений переменных (подстановок) в строку. В JavaScript это можно сделать с помощью шаблонных строк, обрамлённых в обратные кавычки (`). Подстановки внутри шаблонной строки обозначаются знаком доллара и фигурными скобками, то есть так: ${...}. Выражение внутри фигурных скобок будет вычислено и его результат вставлен в строку.

Например, чтобы добавить к цене единицу измерения, мы можем использовать шаблонную строку вида: ${price} ₽/час``.

А можем одновременно и отформатировать число и добавить единицу измерения, допустим, так:

const price = 1500;
const formattedPrice = `${price.toLocaleString()} ₽/час`;

В результате в переменной formattedPrice будет хранится строка 1 500 ₽/час.
