Отображаем все карточки

Чтобы отобразить переменное количество карточек при любой длине массива cards, подойдёт метод map. Во время перебора элементов в массиве, мы сможем создать компонент Card для каждого элемента.

    cards.map((item) => (
  /* Создание компонента Card */
  /* item - очередной элемента массива cards */
))

При динамическом создании компонентов в цикле нужно добавим для React «подсказку», чтобы он мог различить экземпляры компонентов и эффективно обновлял страницу. В качестве такой подсказки обычно используют уникальный идентификатор объекта. И каждому компоненту в цикле назначают служебный параметр key с этим идентификатором.

cards.map((item) => (
                       <Card cardData={item} key={item.id}/>
                     ))

Задача на этом шаге — создать массив компонентов Card. Передать для каждого компонента в параметре cardData свой набор данных. И в конце отобразить массив компонентов Card внутри списка <ul className="cards">.
