Выводим массив характеристик

Нам осталось вывести в шаблоне список характеристик яхты. В карточке характеристики выводятся в виде списка.

          <ul className="card-features">
            <li>2 каюты</li>
            <li>4 спальных места</li>
            ...
          </ul>

Набор характеристик может быть разный, разной длины и последовательности. Для работы с данными переменной длины в JS используются массивы.

          const features = [
            '2 каюты',
            '4 спальных места',
            'аудиосистема, кондиционер',
          ];

Использование массива элементов из переменной в шаблоне позволит нам динамически формировать разметку компонента. Список характеристик может поступать в компонент «снаружи», из параметров. И задача компонента — отрисовать список, а не отдельные элементы. Ответственность шаблона — правильно разместить готовый список в разметке компонента, а сколько будет элементов в списке и в каком порядке они идут, шаблону уже не важно.

Для отображения массива данных в шаблоне можно использовать метод map. На вход метода map подаётся callback-функция, которая будет вызвана для каждого элемента массива. Callback-функция может возвращать заполненный JSX-элемент, например, элемент списка <li>, внутри которого отображается отдельная характеристика.

< 

const featuresList = features.map((feature) => (
              <li>{feature}</li>
            ));
