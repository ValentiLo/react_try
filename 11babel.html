Добавляем статус карточки

В каталоге яхт выделяются популярные. Для них предусмотрен шеврон «Хит продаж»

В вёрстке карточкам, отмеченным как хиты продаж, добавляется класс card-top-seller.

<ul class="cards">
        <li class="card">...  
        <li class="card card-top-seller">...  </li>
      ...
  </ul>

Компоненту Card понадобится новый параметр isTopSeller, чтобы выделить такие яхты. Этот параметр будет принимать логическое значение, и в зависимости от него в карточке добавляется класс card-top-seller. Класс определит визуальное отображение, которое привлечёт внимание к отдельным яхтам и поможет пользователю сделать выбор.

Вы уже использовали синтаксис интерполяции для заполнения атрибута и шаблонные строки для форматирования содержимого элемента. Для вычисления составного класса в зависимости от параметра можно использовать оба подхода.

className={someVariable ? 'class1' : 'class2'}

Фигурные скобки означают применение JS-выражения для вычисления значения атрибута в JSX. Тернарный оператор вернёт одно из двух значений в зависимости от условия. В этом примере вычисляется someVariable и на основе её истинного/ложного значения используется в качестве класса элемента либо class1, либо class2.

Более сложный пример использует оба вида интерполяции:

className={`tab-${isActive ? 'active' : 'inactive'}`}

Этот код определяет динамическое имя класса для элемента JSX. Внешние фигурные скобки нужны для вычисления выражения в JSX. Само выражение — шаблонная строка (окружённая обратными кавычками) с интерполяцией (выражение внутри фигурных скобок ${...}).

Выражение внутри фигурных скобок вычисляет условный оператор isActive ? 'active' : 'inactive', который возвращает строку active или inactive в зависимости от значения переменной isActive. Если переменная isActive равна true, то в имени класса будет использоваться строка active, в противном случае — inactive. Результатом выражения будет строка типа tab-active или tab-inactive.

Иногда нужно только добавить класс по условию, а при невыполнении условия — оставить базовый класс. В этом случае, если условие не выполнено, в условном операторе можно вернуть пустую строку. Например, так:

const className = isActive ? 'active' : '';

Вычисленное значение className можно затем использовать в JSX, поместив его в фигурные скобки внутри атрибута className.

className={`container ${className}`}

Отличие между интерполяцией шаблонной строки в JavaScript и интерполяцией в JSX состоит в том, что последняя может содержать не только строковые значения, но и целые компоненты. В обоих случаях можно использовать любые выражения в качестве значений для интерполяции, включая переменные, выражения и функции.

Вам нужно для начала добавить в компонент Card параметр isTopSeller. Затем установить этот параметр в значение true для второй карточки.

cards.map((item, i) => (
  <Card cardsData={item} isTopSeller={i === 3} key={item.id}/>
))

Комментарии

  1. Порядковый номер карточки, в методе map во втором параметре map((item, i).
  2. Нумерация элементов в массиве начинается с нуля.
  3. Код установит параметр isTopSeller в значение true для четвёртого по порядку элемента массива isTopSeller={i === 3}.
