Начинаем настраивать шаблон карточки

Разметку карточки мы перенесли в JSX. Отлично! Но сейчас она содержит данные из макета. Такую разметку называют «статичной» (неподвижной). Чтобы превратить статичную разметку в компонент, нужно предусмотреть возможность изменения части разметки динамически в зависимости от параметров компонента.

JSX поддерживает интерполяцию, что позволяет встраивать переменные и выражения внутрь элементов JSX. Для этого их нужно заключить в фигурные скобки {...}. Например, чтобы встроить значение переменной name в текст элемента, мы пишем:

const name = 'Кекс';
return <p>Привет, {name}!</p>;

Очевидно, что в карточках изменяется название яхты, её описание и изображение. Начнём с них.

Название яхты отображается в заголовке <h3 className="card-title">, описание в элементе <p className="card-description">>, а изображение в атрибуте src тега <img className="card-img">.

Значения параметров можно получить из переменных name, description и img

Ваша задача на этом шаге изменить шаблон карточки таким образом, чтобы он умел отрисовывать название, описание и путь к изображению из значений соответствующих переменных.

Задачи

  • Отобразите название яхты из переменной name.
  • Отобразите описание яхты из переменной description.
  • Заполните адрес изображения яхты из переменной img.
